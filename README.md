# 🚗 AUTODRIVE – Car Rental & Selling Management System

AUTODRIVE is a modern web-based platform designed to simplify car rental and vehicle purchasing. It allows users to explore available vehicles, rent cars, browse cars for sale, and manage vehicle-related services through a user-friendly interface.

## ✨ Features

- 🚘 Browse available cars for rent and sale
- 🔍 Search and filter vehicles
- 📅 Car rental booking management
- 💰 Vehicle selling and management
- 👤 User registration and login
- 📋 Manage bookings and rental records
- 📱 Responsive and modern user interface
- ⚙️ Admin dashboard for system management

## 🛠️ Technologies Used

- **Backend:** Laravel / PHP
- **Frontend:** HTML, CSS, JavaScript
- **Database:** MySQL
- **Tools:** VS Code, Git & GitHub

## 🎯 Project Objective

To provide a convenient and efficient platform that connects customers with available vehicles for rental and purchase while simplifying vehicle and booking management.

## 🚀 Getting Started

1. Clone the repository.
2. Install dependencies using Composer.
3. Configure your `.env` file.
4. Create and configure your MySQL database.
5. Run database migrations.
6. Start the Laravel development server.

```bash
composer install
php artisan key:generate
php artisan migrate
php artisan serve
```
